## Getting Started (Next 30 Minutes)

### Step 1: Run Data Audit (5 min)

See what data you have and what needs improvement:

```bash
cd hub
npm install chalk  # If not already installed
tsx scripts/audit-and-enrich.ts audit
```

**What you'll see:**
- Total counts (pages, PDFs, embeddings, recommendations)
- Missing metadata (dates, authors, descriptions, tags)
- PDF classification gaps
- Embedding coverage percentage
- Prioritized recommendations

### Step 2: Enrich First 10 Pages (10 min)

Use GPT-4 to fill gaps in your top content:

```bash
tsx scripts/audit-and-enrich.ts enrich 10
```

**What it does:**
- Generates compelling meta descriptions
- Extracts relevant tags
- Infers publication dates
- Identifies authors
- Recalculates quality scores

**Cost:** ~$0.30-0.50 for 10 pages (GPT-4 Turbo)

### Step 3: Classify 10 PDFs (10 min)

Get better metadata for your PDF tools:

```bash
tsx scripts/audit-and-enrich.ts classify 10
```

**What it does:**
- Identifies tool type (CBA, Hierarchy of Values, etc.)
- Categorizes (facilitator-guide, participant-worksheet, etc.)
- Determines target audience
- Extracts SMART tool numbers

Try the new multi-strategy recommendation API:

## Next Steps (This Week)

### 1. Create Knowledge Graph Tables

Run this SQL in your Supabase dashboard:

```sql
-- Content Relationships
CREATE TABLE IF NOT EXISTS content_relationships (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  source_content_id UUID,
  source_type TEXT CHECK (source_type IN ('page', 'pdf', 'interview')),
  target_content_id UUID,
  target_type TEXT CHECK (target_type IN ('page', 'pdf', 'interview')),
  relationship_type TEXT CHECK (relationship_type IN (
    'references', 'prerequisite', 'related_tool', 'same_topic',
    'updated_version', 'translation', 'adaptation', 'example_of',
    'supports', 'contradicts'
  )),
  relationship_strength FLOAT DEFAULT 0.5,
  metadata JSONB,
  created_at TIMESTAMP DEFAULT NOW(),
  verified BOOLEAN DEFAULT false
);

CREATE INDEX idx_content_rel_source ON content_relationships(source_content_id, source_type);
CREATE INDEX idx_content_rel_target ON content_relationships(target_content_id, target_type);
CREATE INDEX idx_content_rel_type ON content_relationships(relationship_type);

-- Conversation Topics (for tracking what users ask about)
CREATE TABLE IF NOT EXISTS conversation_topics (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  conversation_id UUID REFERENCES conversations(id) ON DELETE CASCADE,
  topic_name TEXT NOT NULL,
  topic_category TEXT,
  topic_embedding vector(1536),
  suggested_content_ids UUID[],
  accessed_content_ids UUID[],
  was_helpful BOOLEAN,
  metadata JSONB,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_conversation_topics_conversation ON conversation_topics(conversation_id);
CREATE INDEX idx_conversation_topics_embedding ON conversation_topics
  USING ivfflat (topic_embedding vector_cosine_ops);

-- Theme Nodes (for knowledge graph)
CREATE TABLE IF NOT EXISTS theme_nodes (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  theme_name TEXT NOT NULL UNIQUE,
  category TEXT,
  description TEXT,
  embedding vector(1536),
  confidence_score FLOAT,
  related_themes UUID[],
  supporting_content_ids UUID[],
  mention_count INTEGER DEFAULT 0,
  last_mentioned TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_theme_embedding ON theme_nodes
  USING ivfflat (embedding vector_cosine_ops);
```

### 4. Monitor Performance

Check your new analytics:

```sql
-- See which relationships are strongest
SELECT
  sc1.title as source,
  sc2.title as target,
  relationship_type,
  relationship_strength
FROM content_relationships cr
JOIN scraped_content sc1 ON cr.source_content_id = sc1.id
JOIN scraped_content sc2 ON cr.target_content_id = sc2.id
ORDER BY relationship_strength DESC
LIMIT 20;

-- See which topics users ask about most
SELECT
  topic_name,
  topic_category,
  COUNT(*) as frequency,
  AVG(CASE WHEN was_helpful THEN 1 ELSE 0 END) as helpfulness_rate
FROM conversation_topics
GROUP BY topic_name, topic_category
ORDER BY frequency DESC
LIMIT 20;
```

### Add Intent-Based Embeddings

Extend embeddings to capture *why* content is useful:

```typescript
// Add to your embedding generation:
async function generateIntentEmbedding(content: Content) {
  const intentPrompt = await openai.chat.completions.create({
    model: "gpt-4-turbo",
    messages: [{
      role: "system",
      content: "Extract the primary problems this content solves and who would use it. Return as a clear description."
    }, {
      role: "user",
      content: `${content.title}\n\n${content.content.slice(0, 2000)}`
    }]
  })

  const intentText = intentPrompt.choices[0].message.content

  const embedding = await openai.embeddings.create({
    model: "text-embedding-ada-002",
    input: intentText
  })

  await supabase.from('content_embeddings').insert({
    scraped_content_id: content.id,
    embedding_type: 'intent',
    chunk_text: intentText,
    embedding: embedding.data[0].embedding,
    embedding_metadata: {
      model: 'text-embedding-ada-002',
      generated_at: new Date().toISOString()
    }
  })
}
```

## Measuring Success

### Week 1 Metrics

Track these to see if enhancements are working:

```sql
-- Content quality improvement
SELECT
  AVG(quality_score) as avg_quality,
  COUNT(CASE WHEN meta_description IS NOT NULL THEN 1 END)::FLOAT / COUNT(*) as desc_coverage,
  COUNT(CASE WHEN tags IS NOT NULL AND array_length(tags, 1) > 0 THEN 1 END)::FLOAT / COUNT(*) as tag_coverage
FROM scraped_content;

-- Recommendation effectiveness
SELECT
  cr.recommendation_type,
  COUNT(*) as total,
  AVG(cr.click_count::FLOAT / NULLIF(cr.view_count, 0)) as avg_ctr,
  AVG(cr.confidence_score) as avg_confidence
FROM content_recommendations cr
WHERE cr.created_at > NOW() - INTERVAL '7 days'
GROUP BY cr.recommendation_type;

-- Content relationships
SELECT
  relationship_type,
  COUNT(*) as count,
  AVG(relationship_strength) as avg_strength
FROM content_relationships
GROUP BY relationship_type
ORDER BY count DESC;
```

### Week 2+ Metrics

```sql
-- User engagement with recommended content
SELECT
  DATE(cu.created_at) as date,
  COUNT(DISTINCT cu.user_id) as unique_users,
  COUNT(CASE WHEN cu.action_type = 'view' THEN 1 END) as views,
  AVG(cu.time_spent_seconds) as avg_time_spent
FROM content_usage cu
WHERE cu.recommendation_id IS NOT NULL
GROUP BY DATE(cu.created_at)
ORDER BY date DESC;

-- Most helpful content (via conversation tracking)
SELECT
  sc.title,
  sc.url,
  COUNT(ct.id) as times_suggested,
  AVG(CASE WHEN ct.was_helpful THEN 1.0 ELSE 0.0 END) as helpfulness_rate
FROM conversation_topics ct
JOIN UNNEST(ct.suggested_content_ids) AS content_id ON TRUE
JOIN scraped_content sc ON sc.id = content_id
GROUP BY sc.id, sc.title, sc.url
HAVING COUNT(ct.id) > 3
ORDER BY helpfulness_rate DESC, times_suggested DESC
LIMIT 20;
```

## Troubleshooting

### "Table does not exist" errors

Some tables (like `content_relationships`, `conversation_topics`) need to be created manually. Run the SQL above in Supabase dashboard → SQL Editor.

### "Out of OpenAI credits"

The scripts use GPT-4 Turbo which is cost-effective but not free. Monitor usage:
- Metadata enrichment: ~$0.03-0.05 per page
- PDF classification: ~$0.10-0.15 per PDF
- Relationship extraction: ~$0.10-0.15 per pair

Start with small batches (10-20 items) to test.

### "Embedding index is too slow"

For large datasets (10k+ embeddings), optimize:

```sql
-- Tune IVFFLAT index
CREATE INDEX CONCURRENTLY idx_embeddings_vector_tuned
ON content_embeddings
USING ivfflat (embedding vector_cosine_ops)
WITH (lists = 100);  -- Adjust based on data size
```

### "Recommendations not relevant"

1. **Check embedding coverage**: Run audit to see % of content with embeddings
2. **Verify quality scores**: Low-quality content might be recommended
3. **Adjust thresholds**: In enhanced API, increase `match_threshold` from 0.7 to 0.75
4. **Review relationships**: Check if relationship extraction is working
